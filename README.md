# Fly Away Travel — Frontend

Frontend en React + TypeScript + Vite + TailwindCSS para la API de reserva de vuelos.

## Integrante
- Saúl Baltazar Palomino

## Cómo ejecutar
1. Levantar el backend en http://localhost:8080
2. `npm install`
3. `npm run dev` → http://localhost:5173

## Funcionalidades completdas
- Registro con validaciones y errores del backend 
- Login con JWT en localStorage + nombre del usuario autenticado 
- Búsqueda de vuelos con tabla y filtro por rango de fechas 
- Reserva con mensajes de éxito/error + detalle de reserva 
-  Mis Reservas con localStorage 
- Logout, rutas protegidas y navegación
